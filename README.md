Live portfolio of **Deepak Sharma (deepu0)**: Senior Frontend Engineer @ Target, Founder of [OnlyFrontendJobs.com](https://onlyfrontendjobs.com), Topmate Mentor, and Creator behind [@THEENGINEERBHAI](https://www.youtube.com/@THEENGINEERBHAI) and [@ghumta_firta_techie](https://www.youtube.com/@ghumta_firta_techie).

---

## ⚡ Architecture & Tech Stack

- **Framework:** Next.js 16 (App Router with Turbopack)
- **Runtime:** React 19 & TypeScript Strict Mode
- **Styling:** Tailwind CSS v4 with custom CSS variables
- **Motion & Canvas:** Framer Motion, canvas particle physics
- **SEO:** `schema.org/Person` JSON-LD, OpenGraph cards, Next.js metadata

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/deepu0/portfolio.git
cd portfolio

# Install dependencies
pnpm install

# Start local dev server
pnpm dev

# Build for production
pnpm build
```
